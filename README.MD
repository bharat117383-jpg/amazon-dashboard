# Amazon Prime Video – Exploratory Data Analysis

## Project Overview
An Exploratory Data Analysis (EDA) project that analyzes Amazon Prime Video content using Python.

## Objectives
- Analyze movie and TV show distribution.
- Identify popular genres.
- Explore country-wise content production.
- Compare movies and TV shows.

## Technologies Used
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Jupyter Notebook

## Dataset
- `titles.csv` – Movie and TV show information.
- `credits.csv` – Cast and crew information.

## Project Structure
```text
Amazon_prime_EDA/
│
├── data/
│   ├── titles.csv
│   └── credits.csv
│
├── Amazon_Prime_EDA.ipynb
├── requirements.txt
└── README.md
```

## Key Findings
- Movies are more common than TV shows.
- Drama is the most frequent genre.
- The United States has the highest number of titles.

## How to Run
1. Clone or download this repository.
2. Install dependencies using:
   `pip install -r requirements.txt`
3. Open the Jupyter Notebook.
4. Run the cells sequentially.
